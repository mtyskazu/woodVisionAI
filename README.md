# woodVisionAI
**高精度エッジAI木材検品・座標出力システム**

## プロジェクト概要
本プロジェクトは、IDS製産業用カメラとGPU加速された深層学習（PyTorch）を用い、搬送中の木材（最大4000mm）から「節（Knot）」および「腐れ（Rot）」をリアルタイムで検出し、その絶対座標をPLCへ転送する自動検品システムである。エンコーダ同期により、搬送速度に依存しない正確な位置特定を実現する。

## システムアーキテクチャ

マルチスレッド設計により、撮像・推論・通信を並列化し、レイテンシを最小化する。

1. **Capture Thread**
   - エンコーダパルスに同期したハードウェアトリガーによる画像取得
   - RAWデータ（BayerRG8）の取得とRGB変換

2. **Inference Thread (GPU)**
   - PyTorchモデルによる物体検出（節・腐れのクラス分類と矩形抽出）
   - RTX 4060のFP16演算による高速化

3. **Logic & Transform**
   - 画像内ピクセル座標を材の始点からの絶対座標（mm）に一括変換

4. **Communication Thread**
   - PLC通信プロトコルによる座標データの高速パケット送信
