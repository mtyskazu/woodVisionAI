# カメラ・照明 設置治具 設計仕様

**作成日**: 2026-03-09
**ステータス**: 検討中

---

## 目的

照明比較テストおよび本番運用に向けて、カメラと照明の位置関係を固定する設置治具を設計する。

---

## 制約条件（README.md より）

| 項目 | 値 |
|---|---|
| 作動距離 (WD) | 240 mm（材表面 → レンズ先端） |
| 視野 (FOV) | 200 mm × 126 mm |
| 空間分解能 | 0.103 mm/pixel |
| 材幅 | 150 mm |
| レンズ | 8mm / C-mount |
| カメラ外形 | IDS GV-50C0CP-C-HQ（約 29 × 29 × 41.5 mm） |
| 照明（表面用） | OPB-X22530W（白色）× 1 / OPB-X22530R（赤色）× 1 — 今回の試験対象 |
| 照明（側面用） | OPB-X7530W/R — 今回の試験では未使用 |

## 設計ガイドライン

### 1. カメラ取付

```
         [カメラ]
            │
            │ WD = 240 mm
            │
   ─────────┼─────────  材表面
        FOV 200 mm
```

- **取付方向**: 材表面に対して垂直（真上から真下）
- **WD 240mm の基準**: レンズ先端 → 材表面
- **フランジバック考慮**: C-mount = 17.526mm。カメラ取付面から材表面までの距離はおよそ WD + レンズ長 + フランジバック ≒ 240 + 30 + 18 ≒ **約 288 mm**
- **微調整**: 焦点合わせのため ±20mm 程度の高さ調整機構が必要

### 2. 照明配置

**機材**: OPB-X22530W（白色）× 1、OPB-X22530R（赤色）× 1 の計2本を使用。
**方針**: テスト・本番ともに**1灯構成**を基本とする（試験結果次第で見直し）。

#### 構成: 1灯・片側配置

```
                [カメラ]
   [照明]          │
      ＼  θ       │
        ＼         │
          ＼       │
   ────────────────┼─────────────  材表面
               FOV 200 mm
```

| パラメータ | 推奨値 | 理由 |
|---|---|---|
| **照明角度 θ** | 30〜45° | 正反射をカメラに入れない |
| **照明本数** | 1本（片側） | テスト・本番ともに1灯構成を基本とする |
| **照明モデル** | OPB-X22530 | 有効照射幅 225mm > FOV幅 200mm をカバー |
| **照明距離** | 100〜200 mm | 照度の均一性と強度のバランス |
| **照明位置** | カメラの搬送方向側（上流 or 下流） | 本番でも同配置を再現しやすい |

#### 1灯構成の留意点

| 項目 | 影響 | 対策 |
|---|---|---|
| **片側影** | 照明と反対側に節の影が落ちる | 照明角度を浅く（30°）すると影が長くなるため、35〜45° で調整 |
| **照度ムラ** | 照明近側が明るく、遠側が暗くなる | 照明距離を離す（150〜200mm）ほど均一になるがその分暗くなる |
| **ハレーション** | 片側からの入射のみなので限定的 | 拡散板で軽減 |

> **本番方針**: 1灯構成を基本とする。試験結果で照度ムラ・影が許容範囲外の場合のみ2灯化を検討。

#### 角度別の特性（参考）

| 角度 | 節のコントラスト | ハレーション | 影 |
|---|---|---|---|
| 15〜25°（浅い） | 高い（表面凹凸を強調） | 低い | 強い |
| 30〜45°（中間） | 中〜高 | 低〜中 | 中 |
| 60〜80°（急角度） | 低い | 高い（正反射に近い） | 弱い |

### 3. 拡散板の取付

- 照明の発光面に直接取り付け（DF80-OPB-X22530）
- 脱着可能な構造とし、拡散板有無の比較テストに対応

## テスト用治具（Phase 1 照明比較）

照明比較テストでは、コンベアは不要。固定台上で材を撮像する。

### 最小構成

```
    ┌──────────────────────────────┐
    │        天板（カメラ取付）       │
    │     ┌─────────┐              │
    │     │ カメラ   │  高さ ≒ 288mm │
    │     └────┬────┘              │
    │          │                    │
    │  [照明]  │                    │ ← 照明ブラケット
    │     ＼   │                    │    角度調整可能
    │       ＼ │                    │
    ├──────────┼───────────────────┤
    │      材サンプル                │ ← 台座
    └──────────────────────────────┘
```

- 白色 / 赤色は同じ位置・角度で差し替えてテスト
- 照明ブラケットは1灯分のみ。位置を固定して色だけを変える
- **照明角度: 30°**
- **照明距離: 210 mm**（照明 → 材表面）
- **WD: 210 mm**
- **露光時間: 7564.8 µs（≒ 7.6 ms）— 固定**
- **アナログゲイン: 1.00 — 固定**

### 治具に必要な機能

| 機能 | 仕様 | 用途 |
|---|---|---|
| **カメラ高さ調整** | ±20 mm | 焦点微調整 |
| **照明角度調整** | 15〜60° 可変 | 角度比較テスト |
| **照明距離調整** | 100〜200 mm | 照度調整 |
| **拡散板脱着** | ワンタッチ着脱 | 拡散板有無の比較 |
| **材固定** | 幅 150mm の材を安定保持 | 撮像中のブレ防止 |

### 推奨材料

- フレーム: アルミフレーム（20×20 or 30×30 mm）+ 汎用ブラケット
- カメラ取付: 1/4インチネジ対応マウント or カメラ固定金具
- 照明ブラケット: 角度調整付きクランプ

## 本番設置（Phase 3 コンベア統合時）

### 4面カメラ配置

```
             [カメラ: 表面]
                  │
    [カメラ:    ──┼──    [カメラ:
     左側面]     │        右側面]
                 │
             ────┼────  コンベア搬送方向 →
                 │
             [カメラ: 裏面]
```

- 4台すべて WD = 240mm を維持
- エンコーダトリガーで同時シャッター
- 各カメラに1灯の照明を個別配置（計4灯）— 試験結果で2灯化が必要と判断された場合は計8灯
